Pokédex
Este proyecto es una aplicación web construida con React, Tailwind CSS y React Query que se enfoca en gestionar y visualizar una colección de Pokemones. Fue desarrollada como proyecto de la cátedra de Sistemas Distribuidos en la Facultad de Ingeniería en la Universidad Nacional de Mar del Plata.

Funcionalidades Destacadas
Catálogo Global de Pokémon: Permite la visualización de todos los Pokémon disponibles a través de la PokeAPI.
Detalles de Pokémon: Al seleccionar un Pokémon, el usuario puede acceder a una vista detallada que muestra sus estadísticas, habilidades e información relevante.
Gestión de Favoritos: Ofrece la capacidad de marcar y desmarcar Pokémon como favoritos, gestionando una colección personalizada.
